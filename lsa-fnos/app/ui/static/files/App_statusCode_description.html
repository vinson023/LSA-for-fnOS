1.       操作系统级状态代码

在此场景中，LSA 将 从操作系统（Windows/Linux）获取错误代码和描述并返回相同结果。此场景适用于所有登录模式。如果身份验证失败，LSA 无法从操作系统获取指定的错误代码和描述。

LSA_STATUS_MAIN + 0x0B

1. 注意：更新失败。请检查支持门户，确认固件版本与该控制器兼容。

2. 注意：无法进行联机固件更新。系统必须重启后固件才能生效。

3. 注意：在线固件更新失败。请检查支持门户，确认固件版本与该控制器兼容。

4. 执行任何其他操作前，请先执行断电重置。否则系统行为可能不可预测且未定义。

5. 重启完成后，请注销并重新登录目标服务器。

6. 电源重置完成后，请注销并重新登录目标服务器。

 

可能是 LSA 级别错误：

1. 固件更新失败。您正在尝试将 iMR 固件刷写到 MR 控制器上

2.  固件更新 失败。您正在尝试将 MR 固件刷写到 iMR 控制器上

3.  固件更新 失败。映像的基础版本不匹配

4.  固件更新失败。选定的映像文件等于或超过 16 MB 大小限制

5. 固件更新失败。读取闪存文件失败

6. 此文件等于或超过 16 MB 大小限制。请选择大小小于 16 MB 的 固件映像。

7. 正在刷写的固件版本和 NVDATA 版本与控制器上现有映像相同

8. 由于控制器缓存中保留了脱机或缺失虚拟磁盘的数据，无法执行当前操作。

9. 正在刷写的映像固件版本早于控制器上的现有映像。
