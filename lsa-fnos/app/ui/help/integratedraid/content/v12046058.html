更新控制器固件

LSI 存储管理软件使您能够更新控制器固件。

注意：

LSA 不支持在 IT/IR 控制器上将固件从一个阶段降级到另一阶段。但是，LSA 支持在同一阶段内降级固件。

欲了解更多信息，请参阅 LSA 自述文件 该信息已随您的包裹一起提供。

注意： 在 VMware ESXi 5.5、VMware ESXi 6.0 和 VMware ESXi 6.5 平台上，由于以下限制，您无法通过 LSI 存储管理更新 IT/IR 控制器的固件。

要解决此问题：

  1. 编辑 /etc/sfcb/sfcb.cfg
  2. 添加 httpMaxContentLength: 4194304
  3. 重新启动 LSA 服务 /etc/init.d/sfcbd-watchdog restart
  4. 现在刷新固件。

另请参阅 LSA 自述文件 随软件包一起提供，以获取更详细的信息。

执行以下步骤来更新控制器固件。

  1. 导航到控制器仪表板。
  2. 单击 更新固件。
    将显示 更新固件 窗口。它显示当前控制器固件版本。
  3. 单击 浏览 找到并打开：

    • .bin IR3/IT 控制器的更新文件。

  4. 单击 更新。

    更新固件窗口显示当前控制器固件版本以及可供选择的控制器固件版本。

  5. 选择 确认 复选框并单击 闪存固件。

    更新完成后，将显示一条消息，确认更新成功并显示控制器的新版本固件。

    注意：

    用户对固件的更新可能会导致闪存错误事件。忽略错误消息。

    当刷新 IT 固件、BIOS 或 UFI 时，LSA 会显示一条消息以重新启动服务器，无论固件版本如何。
