查看虚拟磁盘属性

从控制器仪表板的磁盘组中选择虚拟磁盘以查看其属性。

表 1. 虚拟磁盘属性
属性 描述
状态 虚拟磁盘的当前状态。这些选项可用：
  • 最佳
  • 部分降级
  • 降级
  • 脱机
当前读取缓存状态 虚拟磁盘的读取缓存策略。这些选项可用：
  • 无预读
默认读取缓存策略
  • 预读
  • 无预读
当前写缓存状态 虚拟磁盘的写缓存策略。这些可用：
  • 回写
  • 直写
  • 始终回写
默认写缓存策略
  • 默认
  • 启用
  • 已禁用
当前 I/O 策略 虚拟磁盘的当前 I/O 策略。
默认 I/O 策略
  • 直接 I/O
  • 缓存 I/O
准入政策 虚拟磁盘的访问策略。这些选项可用：
  • 读写
  • 只读
  • 隐藏

隐藏 策略仅适用于隐藏的虚拟磁盘。选择后不再适用其他访问策略 隐藏 作为访问策略。
磁盘缓存策略 虚拟磁盘缓存设置。这些选项可用：
  • 不变
  • 启用
  • 已禁用
数据保护 指示数据保护是启用还是禁用。
当前取消映射状态 取消映射的当前状态。
