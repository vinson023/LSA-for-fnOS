更新控制器固件

LSI 存储管理软件使您能够更新控制器固件。

执行以下步骤来更新控制器固件。

  1. 导航到控制器仪表板。
  2. 单击 更新固件。

    将显示 更新固件 对话框，其中显示组件、当前版本、所选版本、当前安全版本和所选安全版本（如果适用）。

  3. 单击 浏览 找到并打开 .rom 文件。

    在 PSOC 固件升级（或降级）期间，如果控制器上存在相同的固件版本或者所选版本低于当前版本，则会显示一条消息。单击确认复选框（强制选项）重新确认该过程。

  4. 单击 更新。
  5. 选择 在线激活 或 离线激活。

    默认情况下， 在线激活 被选中。

    注意： 在线激活 和 离线激活 单选按钮仅适用于 SAS4xxx 控制器。 SAS3xxx 控制器依赖于在线固件更新位，该位通常设置为 在线激活。

    离线激活 需要重新启动系统。

  6. 选择 确认 复选框并单击 闪存固件。

    更新完成后，会出现一条消息，确认更新成功。该消息还显示控制器的新版本固件。

    注意： 对于 SAS3xxx 控制器，您可以使用任何 BIOS 或 EFI 单选按钮刷新 BIOS 和 EFI。 单独的 BIOS 和 EFI 闪存只能在 IR/IT 控制器上执行。
