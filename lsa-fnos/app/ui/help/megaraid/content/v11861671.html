安装和配置的限制

以下是此安装和配置的限制。

  • 控制器不存在状态信息。
  • 只要 LSA 在客户端上运行，就会收集事件。

  • 与 Windows 或 Linux 操作系统上的 LSA 的响应相比，VMware 上的 LSA 的响应速度较慢。

    从客户端首次登录 VMware ESXi 计算机时开始收集事件。只要 LSA 服务正在运行，就会继续收集事件。

  • 当磁盘柜中存在空 物理磁盘 插槽时，无法查看 物理磁盘 操作和属性。
重要： 所有与安全相关的浏览器设置必须设置为标准安全设置。 LSA 是基于 Web 的应用程序，任何浏览器设置更改都会影响 LSA 功能。
