启用计划面板功能

默认情况下，运行 VMware ESXi 操作系统的系统会启用 计划面板 功能。但是，如果运行 Windows、Linux 或其他操作系统，则可通过修改参数启用此功能。

执行以下步骤以启用 计划面板 功能：

  1. 浏览至 C:\Program Files\LSI\LSIStorageAuthority\server\html\files。
  2. 打开 configfile.json 文件。
  3. 在 configfile.json 文件中查找 server 字段。
  4. 根据所用操作系统，将 server 字段中的值更改为：
    • VMware ESXi 操作系统 – 0.
    • Windows 和 Linux 操作系统 – 1.
    • 所有其他操作系统 –2.

    LWA 是独立安装。要为 LWA 服务器启用 计划面板 功能，请将当前 server 字段的值更改为 1 或 2。
