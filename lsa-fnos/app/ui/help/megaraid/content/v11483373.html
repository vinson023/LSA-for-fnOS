更改行为模式

执行以下步骤来更改行为模式和参数：

  1. 在更改控制器模式页面中，选择更改自动配置行为单选按钮。
  2. 从 更改主要自动配置行为下拉列表中，选择适当的行为模式。
    可用的行为模式基于当前的固件支持。
    • 未配置的良好 – 选择此选项后，所有已配置的物理磁盘都会转换为未配置的良好物理磁盘。
    • JBOD – 如果所有物理磁盘均处于未配置的良好状态，选择 JBOD 模式后，所有物理磁盘将自动转换为 JBOD 状态。
    • 单磁盘 RAID 0 – 如果用户选择此选项，则所有物理磁盘都会自动转换为单磁盘 RAID 0。
    • 单磁盘 RAID 0 WB – 如果用户选择此选项，则所有物理磁盘都会自动转换为采用回写策略的单磁盘 RAID 0。
    • 安全 JBOD – 如果所有物理磁盘均处于未配置的良好状态，选择安全 JBOD 模式后，所有物理磁盘将自动转换为安全 JBOD 状态。
    • 安全单磁盘 RAID 0 – 此选项会将处于未配置的良好状态的 SED 物理磁盘转换为安全单磁盘 RAID 0，将非 SED 物理磁盘转换为单磁盘 RAID 0。
    • 安全单磁盘 RAID 0 WB – 此选项会将 SED 物理磁盘转换为安全单磁盘 RAID 0（回写）。
    更改主要自动配置行为 和 更改辅助自动配置行为 如果不允许更改，则下拉列表选择将被禁用。
  3. （可选）要立即更改行为模式，请在更改控制器模式页面选择立即配置单选按钮。

    可用的行为模式基于当前的固件支持。

    • 未配置的良好 – 选择此选项后，所有已配置的物理磁盘都会转换为未配置的良好物理磁盘。
    • JBOD – 如果所有物理磁盘均处于未配置的良好状态，选择 JBOD 模式后，所有物理磁盘将自动转换为 JBOD 状态。
    • 单磁盘 RAID 0 – 如果用户选择此选项，则所有物理磁盘都会自动转换为单磁盘 RAID 0。
    • 单磁盘 RAID 0 WB – 如果用户选择此选项，则所有物理磁盘都会自动转换为采用回写策略的单磁盘 RAID 0。
    • 安全 JBOD – 如果所有物理磁盘均处于未配置的良好状态，选择安全 JBOD 模式后，所有物理磁盘将自动转换为安全 JBOD 状态。
    • 安全单磁盘 RAID 0 – 此选项会将处于未配置的良好状态的 SED 物理磁盘转换为安全单磁盘 RAID 0，将非 SED 物理磁盘转换为单磁盘 RAID 0。
    • 安全单磁盘 RAID 0 WB – 此选项会将 SED 物理磁盘转换为安全单磁盘 RAID 0（回写）。
  4. 选择适当的行为模式，然后单击 更改。
