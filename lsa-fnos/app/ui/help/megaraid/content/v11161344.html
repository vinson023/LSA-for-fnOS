通过网络地址转换访问 LSA

网络地址转换 (NAT) 允许使用未注册 IP 地址的私有 IP 网络连接到 Internet。 NAT 运行在路由器上，通常将两个网络连接在一起，并将内部网络中的私有地址转换为合法地址。

要通过 NAT 环境访问 LSI 存储管理应用程序，LSA 服务器必须了解有关 NAT 服务器设置的一些信息。

执行以下步骤配置参数 lsa.conf 文件在 会议 目录。

  1. 打开 lsa.conf 文件在 LSIStorageAuthority/conf 目录。
  2. 指定公共 IP nat_ipv4_ipv6.

    例如，如果配置的公共 NAT IP 地址为 135.24.227.198，则必须指定 nat_ipv4_ipv6 = 135.24.227.198。

  3. 重新启动 nginx 服务和 LSA 服务以使更改生效。

    如果您有多个公共 NAT（例如，135.24.227.198、135.24.227.199、fe80::dc8d:e156:41e1:b06），则必须将它们指定为 nat_ipv4_ipv6 = 135.24.227.198、135.24.227.199、fe80::dc8d:e156:41e1:b06。
