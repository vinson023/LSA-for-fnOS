从远程服务器发现页面管理服务器

LSI 存储管理允许您设置要监视和管理的服务器列表。执行以下步骤来管理服务器：

  1. 开 远程服务器发现 页面，单击 转到 – 管理服务器页面 链接。
    将显示 网关 – 身份验证 对话框。
  2. 输入网关服务器的管理员凭据。
    1. 选择其中之一 域名 或 主机 作为下拉列表中的选项。
    2. 在各自的字段中指定用户名和密码。
    网关服务器将登录凭据保存在加密文件中。
  3. 单击 登录。
    远程服务器发现 页面切换到 管理服务器 页。
在 远程服务器发现 或 管理服务器 页面，您可以：

  • 查看托管服务器列表及其健康状态。

  • 从列表中添加和删除受管服务器。

    有关更多信息，请参阅 添加托管服务器 和 删除托管服务器。

  • 重新发现服务器或返回 远程服务器发现 页。

  • 使用 IP 地址或主机名手动发现服务器。

    请参阅 手动发现服务器。

  • 使用不同操作系统类型的复选框仅选择与该特定操作系统关联的服务器进行显示。
  • 在搜索框中指定服务器的 IP 地址以显示该特定服务器。

  • 之间切换 列表 和 网格 单击查看 List/Grid icon。

    默认情况下，LSA 在网格视图中显示所有服务器。
