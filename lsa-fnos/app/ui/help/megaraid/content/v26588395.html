使用 LDAP 身份验证

要访问 LDAP 服务，LSI 存储管理服务器必须了解有关 LDAP 服务器设置的一些信息。除了 LDAP 身份验证的用户名和密码详细信息之外，LSA 后端还必须知道一些参数才能启用身份验证。执行以下步骤来配置这些参数 lsa.conf 文件在 LSIStorageAuthority/conf 目录。
  1. 打开 lsa.conf 文件在 LSIStorageAuthority/conf 目录。
  2. 为 ldap_mode 字段输入值。设置为 0 时，将禁用 LSI 存储管理软件的 LDAP 身份验证；设置为 1 时，将启用 LDAP 身份验证。

    示例：

    LDAP Login
    ldap_mode = 1
  3. 在 ldap_server 字段中输入 LDAP 服务器主机名。此值用于连接指定的 LDAP 服务器以进行用户身份验证。

    示例：

    # LDAP Server
    ldap_server = <IP LDAP 服务器地址>
  4. （可选）在 ldap_protocol_version 字段中输入 LDAP 协议版本。此值定义用于创建 LDAP 会话的协议。

    示例：

    # LDAP Protocol version
    ldap_protocol_version = v3
    默认值为 v3.
  5. 在 ldap_binding 字段中输入 LDAP 身份验证方式。在 LDAP 中，身份验证通过 Bind 操作提供。LDAP 支持以下三种身份验证模式：
    • 匿名 – 当创建 LDAP 会话时，即 LDAP 客户端连接到服务器时，会话的身份验证状态将设置为匿名模式。
    • BASIC（默认） – 最简单的客户端身份验证形式是使用明文密码绑定到服务器。这种机制存在安全问题，因为密码可以从网络上读取。
    • 安全 – 更安全的方法是使用简单身份验证和安全层 (SASL) 身份验证机制，例如 DIGEST-MD5[4]。该方法基于客户端和服务器都已知的加密，允许简单的质询-响应方案。 SASL认证机制还能够协商数据加密以保护后续操作。

    示例：

    # LDAP_BINDING
    ldap_binding = BASIC
  6. （可选）在 ldap_port_number 字段中输入 LDAP 服务器端口号。

    示例：

    # LDAP Port Number = 636
    ldap_port_number = 389
  7. 在 dn_details 字段中输入 DN（专有名称）详细信息，格式如下：

    示例：

    # LDAP_DN_DETAILS
    dn_details={"DN":[{"key":"DC","values":["ldapdomain"]},{"key":"DC","values":["com"]},{"key":"ou","values":["TEST"]}]}
    其中：
    • DC – 此属性包含域组件类型。
    • ou – 此属性包含组织单位名称。
  8. （可选）在 readOnly 字段中输入 LDAP 用户访问权限详细信息。可用值如下：
    • 1（默认）– 只读访问。
    • 0 – 完全访问。
  9. 重新启动 nginx 服务和 LSI 存储管理服务以使更改生效。
