使用高级配置选项创建新的存储配置

高级配置过程提供了创建新存储配置的简单方法。与简单配置相比，高级配置为您提供了更大的灵活性，因为您可以在创建虚拟磁盘时选择磁盘和虚拟磁盘参数。此外，您可以使用高级配置过程来创建跨区磁盘组。
注意： 当物理磁盘位于 准备移除 状态，您无法使用该物理磁盘创建虚拟磁盘。
执行以下步骤来创建高级存储配置。
  1. 在服务器仪表板或控制器仪表板上，选择 配置 > 高级配置。
    将显示 高级配置 窗口。
  2. 从以下列表中为磁盘组选择 RAID 级别 RAID 级别设置 列表。
  3. （可选）单击 比较和选择 查看每个 RAID 级别的详细信息。
    另请参阅 RAID 级别 了解更多信息。

    当您使用高级配置时，RAID 控制器支持以下 RAID 级别。

    • 单磁盘 RAID 0 (SDR0)
    • RAID 0
    • RAID 1
    • RAID 5
    • RAID 6
    • RAID 10
    • RAID 50
    • RAID 60

    窗口文本给出了您选择的 RAID 级别的简要描述。您可以选择的 RAID 级别取决于可用磁盘的数量。

    注意： 当选择 SDR0 以外的任何 RAID 级别时，仅列出 MDRO 磁盘。添加 SDR0 RAID 级别是为了帮助您使用 SDR0 磁盘创建 SDR0 虚拟磁盘。不支持对单磁盘 RAID 0 虚拟磁盘执行带预读的 UNMAP 和 WSUNMAP。
  4. （可选）如果要应用加密逻辑来保护虚拟磁盘中的数据，请选择 安全 复选框。

    您可以将热备盘添加到除 RAID 0 之外的所有 RAID 级别。您还可以仅在存在具有安全功能的磁盘时创建安全虚拟磁盘。当没有受保护的磁盘时，此复选框将被禁用。

  5. （可选）完成以下步骤之一以回收未使用的存储空间。
    注意： 以下选项仅在支持 UNMAP 和 Write Same UNMAP 的磁盘可用时适用。
    • 如果要在创建虚拟磁盘之前在物理磁盘上执行加密擦除操作，请选择 加密擦除 复选框。
      警告： 此操作将删除磁盘中的所有数据。
    • 若要启用 UNMAP/Write Same UNMAP 以回收未使用的存储空间，请选择 启用 UNMAP/Write Same UNMAP 复选框。

    您可以将热备盘添加到除 RAID 0 之外的所有 RAID 级别。此外，仅当存在具有安全功能的磁盘时，您才能创建安全虚拟磁盘。当没有受保护的磁盘时，此复选框将被禁用。

  6. 单击 下一步。
  7. 单击 添加物理磁盘 将物理磁盘添加到磁盘组。
    请参阅以下部分了解更多信息：
    • 有关如何添加物理磁盘的信息，请参阅 添加物理磁盘。
    • 有关将热备盘添加到磁盘组的信息，请参阅 在配置创建期间添加热备盘。
  8. 使用滑块选择跨度深度。
  9. 单击 添加虚拟磁盘 将虚拟磁盘添加到磁盘组。
    将显示 虚拟磁盘设置 窗口。

    有关配置虚拟磁盘的信息，请参阅 添加虚拟磁盘。

  10. 单击 添加虚拟磁盘。
  11. 单击 完成。
    如果存储配置成功完成，则会出现一条确认消息。
