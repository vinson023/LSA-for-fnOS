管理 VMware ESXi 操作系统上的 LSA

本节概述了在 VMware ESXi 操作系统上运行和管理 LSA 所必需的安装前和安装后要求。

从 VMware ESXi 7.x 及更高版本开始，可以通过直接安装 LWA 来管理 VMware ESXi 。

注意： 对于 ESXi 7.x 之前的版本，LSA 无法直接安装在 VMware ESXi 操作系统上。安装在 VMware ESXi 7.x 及更低版本上的 LSA 通过安装在同一子网中 Linux 或 Windows 计算机上的 LSA 客户端进行管理。

  1. 提供商服务

    在从 LSA 客户端（Windows 和 Linux）执行 VMware ESXi 发现之前，请确保提供商服务已启动并正在运行。

    执行以下命令以确保提供程序服务已在 VMware ESXi 上启动并运行：

    /etc/init.d/slpd status

    /etc/init.d/sfcbd-watchdog status

  2. 配置变更详情

    如果有任何配置更改，请确保执行以下操作：

    • /etc/init.d/sfcb-watchdog stop
    • /etc/init.d/slpd stop
    • /etc/init.d/slpd start
    • /etc/init.d/sfcb-watchdog start

  3. 存储控制器

    确保 VMware ESXi 上的存储控制器具有正确的配置（固件和驱动程序）并且存储控制器在通过 LSA 连接之前按预期工作。以下命令有助于验证是否检测到控制器：

    枚举实例 cim_system lsi/lsimr13

  4. 网络通讯详情

    网络通信是 VMware ESXi CIM 提供程序和 Broadcom 管理软件之间正确通信的关键要素。通过进行以下更改来确保网络设置正确：

    • 在对 VMware ESXi 主机执行初始配置时，提供正确的主机名和 IP 地址。参考 如何在 VMware ESXi 上配置网络？ 了解更多信息。
    • 对于未配置 DNS 的网络，必须按如下方式编辑安装 LSA 系统上的 hosts 文件：

    1. 添加一个条目以将 VMware 主机的 IP 地址与主机名进行映射，以便发现过程正确进行。如果没有此条目，VMware 主机将被发现为 0.0.0.0.

    2. 添加一个条目以将本地主机的实际 IP 地址与其主机名进行映射。默认情况下，环回地址的条目会出现在主机文件中，并且不应将其删除，以确保正确传送异步事件通知 (AEN)。例如，如果 135.24.228.136 是 VMware 主机的 IP 地址， 135.24.228.137 是 Linux 主机的 IP 地址，必须在 主机 文件： 
      135.24.228.136 dhcp-135-24-228-136.lsi.com dhcp-135-24-228-136 #VMware
      135.24.228.137 dhcp-135-24-228-137.lsi.com dhcp-135-24-228-137 #Linux
      注意： 确保端口 2463 未被防火墙阻止。

仅在以下操作系统上的 LSA 网关安装中支持 VMware ESXi 的远程管理：

  • 微软 Windows 服务器
  • RHEL
  • SUSE Linux

Windows 和 Linux 步骤

需要在 Windows/Linux 客户端上执行以下步骤：

注意： 客户端和服务器应该在同一子网中。
  1. 确保端口 2463 未被防火墙阻止。
  2. 在网关安装模式下安装最新的 LSA 客户端。
  3. 启动 LSA。
  4. 确保 LSA 服务已启动并正在运行。
  5. 确保发现网络中的其他 LSA 服务器。
  6. 确保 VMware IP 被发现作为 远程服务器发现 页。
  7. 使用 VMware 凭据登录，通过 LSA 客户端监控和管理存储控制器。

在 VMware ESXi 环境上配置网络

  • 默认情况下，在 VMware ESXi 操作系统安装过程中，应适当配置 IP 和主机名。

  • 如果已安装的 VMware ESXi 操作系统从一个网络移至另一个网络，并且主机名映射不正确，请按照以下链接中提到的步骤配置网络和主机名：

    如何在 VMware ESXi 上配置网络？

多子网配置

  • CIMOM 服务器中的 CURL 错误导致上层 (CIMProvider-->LSA) 受阻。如果服务器位于不同的子网中或者存在任何不正确或不完整的 AEN 订阅，则会发生此错误。为了避免此错误，客户端和服务器必须位于同一子网中。必须使用 CIMClient 删除任何不完整的 AEN 订阅。

    要查看现有订阅，请输入：

    主机索引-s

    要删除现有订阅，请输入：

    主机索引-d -k <处理程序名称>

    例如， 主机-ind -d -k dhcp-x.y.z.k.dhcp.company.net_LSA_127.0.0.1

    如果上一个命令在最新版本的 VMware ESXi 中失败，请使用以下命令 索引配置文件。
    • 查看现有订阅： indcfg-|
    • 清除订阅： indcfg-c
    在 VMware 服务器中进行任何更改后，重新启动或重新引导 sfcb 服务。
    • 要重新启动服务器，请使用： 
      esxcli system wbem set -e 0
esxcli system wbem set -e 1

进行任何更改后，请重新启动 sfcb 服务或重启 VMware 服务器。
