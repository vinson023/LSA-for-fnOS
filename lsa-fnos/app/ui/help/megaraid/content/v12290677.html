收集 Windows 和 Linux 操作系统日志

成功安装 LSA 后，您可以重新创建问题以收集 Windows 和 Linux 所需的日志文件。

执行以下步骤：

  1. 停止 LSAService.
  2. 浏览至 LSA_HOME/会议 目录并打开 LSA.conf 文件。
    重要： 在 Windows 操作系统中， LSA_HOME 该目录只能由管理员访问。
  3. 在 LSA.conf 文件中查找 log_level 字段。
  4. 修改现有的或默认值日志级别 字段到 64.
  5. 在 LSA.conf 文件中查找 log_cache_mode 字段。
  6. 修改现有的或默认值日志缓存模式 字段到 0.
  7. 浏览至 LSA_HOME/logs 目录并删除 logs.txt 文件。
  8. 重新启动 LSAService.
  9. 重现问题后，请提供 LSA_HOME/logs 目录中的 logs.txt 文件。
