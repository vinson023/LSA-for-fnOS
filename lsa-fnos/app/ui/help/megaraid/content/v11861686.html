LSA 与 VMware ESXi 的差异

以下是管理 VMware 服务器时 LSA 的一些差异。

  • 以下限制适用于通过应用程序公开的系统信息：
    • 仅显示主机名。
    • 不支持控制器健康信息。
  • 身份验证支持：LSI 存储管理软件允许使用 VMware 的用户 ID 和密码进行 CIMOM 服务器身份验证。
  • 事件记录：事件日志记录支持可用于 VMware ESXi 操作系统，但其工作方式与正常的 LSI 存储管理框架模式不同。连接到 VMware ESXi 系统的 LSA 客户端的事件日志记录功能的行为如下：
    • 系统日志记录在远程服务器中，而不是记录在 VMware ESXi 服务器中。
    • 查看日志 选项允许您查看保存在文本文件中的日志 事件记录器 对话框。
    • 与连接到 Windows 或 Linux 主机的客户端相比，连接到 VMware ESXi 主机的客户端在任何固件更新后刷新 LSA GUI 的速度较慢。
  • VMware ESXi 仅支持 网关 安装。不支持 StandAlone、DirectAgent 和 LWM 安装模式。
  • 以下操作系统上安装的 LSA 网关支持 VMware ESXi：
    • 微软 Windows
    • RHEL
    • SUSE Linux
