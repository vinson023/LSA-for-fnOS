使用 CacheCade Pro 2.0 功能

注意： 此功能仅适用于支持 CacheCade 的控制器。

CacheCade Pro 2.0 读写缓存软件可智能、动态地管理频繁访问的数据，并将其从硬盘 (HDD) 虚拟磁盘复制到性能更高的 SSD 缓存层，无需手动配置混合阵列。将最常访问的数据（热点）复制到闪存缓存，可减少主硬盘 (HDD) 阵列上的耗时事务，从而降低延迟并提高读写性能。

CacheCade Pro 2.0 是业界首款在 SSD 上提供基于控制器的读写缓存的软件解决方案，可显著增强上一代 CacheCade 软件实现的性能增益。添加写缓存支持后，读写密集型工作负载（例如 Exchange 服务器、高性能计算 (HPC) 应用程序、Web 2.0 和其他 I/O 密集型 OLTP 数据库工作负载）将获得显著的性能提升。

  • 修改 CacheCade 虚拟磁盘属性
  • 在虚拟磁盘上启用 SSD 缓存
  • 禁用虚拟磁盘上的 SSD 缓存
  • 清除具有 CacheCade 虚拟磁盘的控制器上的配置
  • 删除 CacheCade – SSD 缓存虚拟磁盘
