控制器模式管理

控制器模式管理功能允许您在固件支持的不同控制器模式和行为模式之间切换。使用控制器模式管理功能，您可以在以下控制器模式和行为模式之间切换。

  • 控制器模式：
    • RAID
    • HBA/eHBA
  • 行为模式
    • JBOD
    • 安全 JBOD
    • 未配置的良好
    • 单磁盘 RAID 0
    • 单磁盘 RAID 0 WB
    • 安全单磁盘 RAID 0
    • 安全单磁盘 RAID 0 WB

有关行为模式和参数的更多信息，请参阅 更改行为模式。
