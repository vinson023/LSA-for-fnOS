在网关/独立安装程序上配置防火墙 (Linux)

您可以在 Linux 操作系统上配置网关/独立安装程序防火墙。在大多数 Linux 系统中，默认情况下会接受所有入站请求。您还可以检查 iptables 条目以验证配置规则。

要验证任何 Linux 系统中设置的配置规则，请执行以下命令：

iptable-L

如果配置规则阻止访问 LSA，请运行以下命令以允许输入连接到 LSA：

iptables -I INPUT -p tcp --dport <网络服务器端口> -j ACCEPT

例如，如果 LSA 的 nginx 端口号是 2463，则必须运行 iptables -I 输入 -p tcp -dport 2463 -j 接受 命令。
