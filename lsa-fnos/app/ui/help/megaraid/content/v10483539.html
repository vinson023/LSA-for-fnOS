查看物理磁盘属性

从控制器仪表板的磁盘组中选择一个物理磁盘以查看其属性。下图和表格描述了物理磁盘属性。

表 1. 物理磁盘属性
属性 描述
设备/永久 ID 由制造商分配的物理磁盘的设备 ID。
磁盘柜 : 插槽 所连接磁盘柜的插槽号。
状态 物理磁盘的当前状态。
暴露为 为了区分物理磁盘，磁盘被公开为以下磁盘之一：
  • JBOD
  • 物理设备
型号 物理磁盘的型号。
供应商 实体的供应商。
序列号 物理磁盘的序列号。
屏蔽计数 护盾计数器值。
强制大小 一种磁盘属性，指示磁盘被强制（强制）的容量，以使其与名义上具有相同容量的其他磁盘兼容。
原始容量 在应用任何强制模式以减少容量之前磁盘的实际全部容量。
一般特性
SAS 地址 0 物理磁盘的全球通用名称 (WWN)。
可用速度 设备支持的最大速度。
温度 物理磁盘的温度。
固件修订级别 物理磁盘的固件修订级别。
电源状态 电源状态显示以下状态：
  • 开 – 物理磁盘已启动。
  • 省电 – 物理磁盘停转。
取消映射功能 设备支持的最大速度。
Write Same UNMAP 功能 回收未使用的存储空间。
物理扇区大小 磁盘物理扇区的大小。可能的选项是 4 KiB 或 512 B。
介质错误计数 与 LUN 通信时检测到的介质错误数。
多路径 如果磁盘处于多路径状态，则路径的 EID 和插槽号。
多端口 如果磁盘处于多端口状态，则路径的 EID 和插槽号。
当前写缓存 LUN 的当前写缓存设置。
默认写缓存 LUN 的默认写缓存设置。
已配置备件 指示磁盘是否是已配置的备用磁盘。
紧急备用盘 指示磁盘是否为紧急备用盘。
Shield 诊断完成时间 指示屏蔽诊断完成时间。仅当控制器支持屏蔽状态时才会显示此属性。
已启用 ATA 安全性 指示 SATA 安全功能是启用还是禁用。
磁盘权限被锁定 如果重复出现身份验证失败，则会出现此状态。
