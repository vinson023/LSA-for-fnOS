VMware 上的虚拟磁盘操作行为

在 LSA 客户端上，当您选择多个虚拟磁盘来执行磁盘初始化、一致性检查、磁盘擦除等操作时，VMware ESXi 服务器可能会超时，从而导致正在执行的操作延迟。

由于请求的操作是进程密集型的并且需要很长时间才能完成，因此 LSA GUI 可以转换为空闲状态，直到请求的操作完成或 VMware ESXi 服务器超时。在此状态（LSA GUI 的空闲状态）期间，您无法对 LSA GUI 执行任何其他操作。

虽然 LSA 客户端正在后台处理请求的操作，并且需要比平常更多的时间才能完成，但 LSA GUI 会转换为空闲状态，不允许您执行任何其他操作；您可能会认为 LSA GUI 已挂起，因为您看不到后台发生的情况。

您可以通过启用 计划面板 功能解决此问题。以下是启用计划面板功能的一些优点：

  • 在多个虚拟磁盘上执行任何进程密集型操作（例如磁盘初始化、一致性检查、磁盘擦除等）时，会显示“计划面板”屏幕，其中显示虚拟磁盘的目标 ID 以及正在执行的操作的状态。

  • 该计划面板屏幕在每个过程完成时更新，实时指示请求是否正在处理。

  • 关闭 仅当所有正在执行的操作完成时，“计划面板”屏幕上才会启用“计划面板”按钮，因此您仅在启用该按钮时才可以关闭“计划面板”屏幕。

  • 在操作完成之前，您无法在 LSA GUI 上执行任何其他操作。

  • 修改计划面板的时间限制
