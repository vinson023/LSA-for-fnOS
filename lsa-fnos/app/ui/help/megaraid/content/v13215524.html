在 ESXi 服务器上配置提供程序

执行以下步骤在 ESXi 服务器上配置提供程序以接收最佳事件通知：

  1. 通过运行以下命令停止提供程序服务 /etc/init.d/sfcbd-watchdog start 命令。
  2. 将 /etc/cim/lsi 目录中的 providerTraceLog.properties 文件复制到临时目录。
  3. 修改 providerTraceLog.properties 并添加以下值：

    LSA=true

  4. 保存 providerTraceLog.properties 文件。
  5. 将临时目录中的 providerTraceLog.properties 文件复制到 /etc/cim/lsi 目录并覆盖原文件。
  6. 通过运行以下命令重新启动 Provider 服务 /etc/init.d/sfcbd-watchdog start 命令。
