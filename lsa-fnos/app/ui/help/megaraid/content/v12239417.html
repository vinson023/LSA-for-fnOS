在 InDirectAgent 安装程序上配置防火墙

LSA 使用 SMI-S 提供程序在 VMware 环境中发现和管理其存储控制器。为了发现 SMI-S 提供程序可用的 ESXi 服务器，LSA 使用 SLP 作为发现机制。 CMISLP 通告并允许远程系统发现 CIM 服务器。 CIMHttpServer 是一个 CIM 服务器，需要与 SMI-S Provider 进行交互。

您可以在 VMware 环境中配置 DirectAgent 安装程序防火墙。

要检查防火墙是否启用，请执行以下命令：

esxcli 网络防火墙获取

如果启用了防火墙，则应在规则集中启用 CIMSLP 服务。要检查规则集中是否启用了 CIMSLP 服务，请执行以下命令：

esxcli 网络防火墙规则集列表

如果 CIMSLP 的规则 ID 设置为 false，则 CIMSLP 被禁用，并且 LSA 将无法发现 CIM 服务。要启用 CIM 服务，请执行以下命令：

esxcli 网络防火墙规则集 --enabled true --ruleset-id=CIMSLP

同样，应启用 CIMHttpServer，以便它可以与 SMI-S Provider 交互。
