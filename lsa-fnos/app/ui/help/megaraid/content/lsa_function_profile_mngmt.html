功能配置文件管理

执行以下步骤即可。

  1. 选择 操作 > 功能配置文件管理 在控制器仪表板上。

    将显示 功能配置文件管理 页面。

    表 1. 功能配置文件管理属性
    属性 描述
    配置文件 ID 显示配置文件的唯一标识符。
    当前 指示该配置文件是否是当前配置文件。
    已请求 指示该配置文件是否是所请求的配置文件。
    可选 指示用户是否可以选择此配置文件。
    可强制选择 指示用户是否只能通过强制选项选择此配置文件。
    功能类型 显示配置文件的函数类型。
    起始功能 ID 显示配置文件的启动功能 ID。
    控制器最小功能 显示支持的最少控制器功能。
    最大控制器功能 显示支持的最大控制器功能。
    队列/向量 显示支持的队列和向量。
  2. 选择第一列中的单选按钮，然后单击 保存 更改当前配置文件。
  3. 重新启动系统以使更改生效。
