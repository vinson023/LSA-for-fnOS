在 Windows 中添加翻译后的名称

对于非英语版本的 Windows，请完成以下步骤。
  1. 停止 LSAService.
  2. 浏览至 LSA_HOME/会议 目录并打开 LSA.conf 文件。
    重要： 在 Windows 操作系统中， LSA_HOME 该目录只能由管理员访问。
  3. 将管理员组的本地化名称添加到 LSA.conf 文件中的 full_access_groups。

    这允许用户在登录后拥有 LSA 的完全访问权限。

  4. 将 Authenticated Users 组的本地化名称添加到 LSA.conf 文件中的 readonly_access_groups。

    这允许用户在登录后拥有 LSA 中的读取访问权限。

  5. 重新启动 LSAService，然后继续登录。
