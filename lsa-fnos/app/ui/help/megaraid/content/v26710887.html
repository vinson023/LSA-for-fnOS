在 Linux 中添加翻译后的名称

对于非英语版本的 Linux，请完成以下步骤。
  1. 使用 /etc/init.d/LsiSASH stop 命令停止 LSAService。
  2. 导航至 LSA_HOME/会议 目录并打开 LSA.conf 文件。
  3. 将根组的本地化名称添加到 LSA.conf 文件中的 full_access_groups。

    这将允许用户在登录后拥有 LSA 的完全访问权限。

  4. 将用户组的本地化名称添加到 LSA.conf 文件中的 readonly_access_groups。

    这将允许用户在登录后拥有 LSA 的读取访问权限。

  5. 使用 /etc/init.d/LsiSASH start 命令重新启动 LSAService，然后继续登录。
