手动发现服务器

LSI 存储管理自动发现同一子网中的服务器。然而，使用 手动发现 上可用的选项远程服务器发现页面中，您可以使用 IP 地址或服务器的主机名手动发现服务器。 手动发现 选项使您能够发现和管理子网之外的服务器。

手动发现 除非服务器是以下服务器的一部分，否则服务器运行状况不会得到更新 自动发现 列表。如果 手动发现 服务器是 自动发现 列表，然后 手动发现 服务器将被删除并显示为自动发现的服务器。

添加相同的服务器 手动发现 不建议采用不同的形式（不同的 IP/主机名）。添加同名服务器会导致同一个服务器在列表中出现多次 手动服务器 或 远程发现 页。

从以下位置执行以下步骤 远程服务器发现 页面来手动发现子网之外的服务器。

  1. 在 远程服务器发现 页面，单击 手动发现

    将出现“手动发现”对话框。

  2. 指定您希望发现的 IP 地址或位于 LSA 子网之外的服务器的主机名。
  3. 单击 搜索

    根据您指定的服务器的IP地址或主机名，显示对应的服务器。

  4. 单击 添加 将新发现的服务器添加到托管服务器列表中。
    1. （可选）如果您不需要在受管服务器列表中列出该服务器，请单击 删除手动添加的服务器 图标以删除服务器。
  5. 单击 登录 登录服务器
  6. 指定服务器的管理员凭据并单击 登录。

    手动添加的服务器现在显示或列出在“远程服务器发现”页面上。

您还可以选择从远程服务器发现列表中删除该服务器，方法是单击 删除手动添加的服务器 图标。
