UNMAP 功能特性行为

LSA MegaRAID 7.8 设计及更高版本的行为包括以下行为。

  • 显示物理磁盘属性，以及物理磁盘是否支持 UNMAP。
  • 显示物理磁盘功能，并指示该物理磁盘是否可用于创建支持 UNMAP 的虚拟磁盘。
  • 允许用户通过虚拟磁盘修改属性中的“启用/禁用”选项修改虚拟磁盘的 UNMAP 功能。
  • 允许用户创建支持 UNMAP 的虚拟磁盘。

LSA MegaRAID 7.8 设计的行为包括以下限制。

  • EPD/JBOD 设计不支持 UNMAP 功能。
  • 由于 MegaRAID 固件 API 的更改，主机软件应用程序无法在 MegaRAID 7.8 之前的设计中支持固件。
