查看控制器属性

控制器仪表板显示基本控制器属性。单击 图标可查看控制器的高级属性。

单击 下载所有控制器属性 链接，以 .JSON 格式下载属性。

表 1. 基本和高级控制器属性
属性 描述
基本控制器属性
序列号 控制器的序列号。
SAS 地址 控制器的 SAS 地址。
驱动程序版本 控制器的驱动程序版本。
PCI 地址 分配给控制器的唯一地址。
PCI_供应商_ID 分配给特定供应商的唯一控制器 ID。
PCI 子系统供应商 ID 有关控制器的其他供应商 ID 信息。
PCI 设备 ID 由制造商分配的设备 ID。
PCI 子系统 ID 由制造商分配的附加设备 ID。
挥发性特性 查看控制器和物理磁盘的易失性属性。
高级属性
NVRAM 存在 指示控制器上是否存在非易失性随机存取存储器 (NVRAM)。
支持屏蔽状态 控制器是否支持屏蔽状态。
阵列卡电池/超级电容 指示控制器是否支持关联的 阵列卡电池/超级电容 状态管理。
NVRAM 大小 指示控制器的NVRAM的容量。
SSD 防护 SMART 错误 指示控制器上是否启用了 SSD Guard 功能。
设备报告顺序 指示控制器上的设备报告顺序。
第一个设备永久 ID 表示控制器上第一个设备的永久ID。
电源状态属性
未配置磁盘的节能 指示是否启用了未配置磁盘上的节能功能。
热备盘节能 指示是否启用了热备盘节能功能。
停转时间 显示磁盘停转时间（以分钟为单位）。
固件属性
固件软件包版本 控制器的固件软件包版本。
固件版本 控制器的固件版本。
全部在线固件更新 指示固件中是否启用了在线固件更新功能。
安全属性
安全功能支持 指示控制器上的安全（加密）功能状态。
安全已启用 指示安全性是否启用。
紧急备用盘属性
紧急备用盘 显示控制器的紧急备用盘属性。可设置为 未配置的良好 或 未配置的良好和全局热备盘。
用于 SMART 错误的紧急备用盘 指示是否配置紧急备用盘进行预测分析。
控制器模式属性
控制器模式 显示当前工作模式。
控制器主要自动配置行为 显示主要的自动配置行为。
控制器辅助自动配置行为 显示辅助自动配置行为。
快照转储属性
通过重置保存计数 通过重置保存计数。
