在网关/独立安装程序上配置防火墙 (Windows)

您可以在 Windows 操作系统上配置网关/独立安装程序防火墙。

防火墙配置文件是一种对设置（例如防火墙规则、连接安全规则等）进行分组的方式，这些设置根据系统的连接位置应用于系统。

Windows 操作系统具有三个配置文件， 公共, 私人, 或 域名。您必须根据您的连接类型适当启用这些配置文件之一。

启用防火墙后，入站设置必须将 LSA 作为例外。默认情况下，入站设置会阻止所有传入连接，除非指定为规则或例外。您必须添加 nginx.exe \端口号 作为一个例外。

执行以下步骤添加 nginx.exe\端口号 作为例外：

  1. 前往控制面板 > Windows 防火墙 > 允许程序或功能通过 Windows 防火墙。
  2. 选择 允许另一个程序。
  3. 浏览到安装 LSI 存储管理的文件夹。
  4. 从 LSI存储管理机构 安装文件夹，选择 nginx.exe。

    通常 nginx.exe 安装在 C:\Program Files\LSI\LSIStorageAuthority\server 位置。

    nginx.exe 是 LSA 用作与远程系统的接口的 Web 服务器。

  5. 单击 添加 或选中复选框以允许 nginx.exe 作为一个例外。
  6. 单击 确定。

    或者，您也可以创建新规则并将配置文件类型设置为从防火墙取消阻止 LSA。
